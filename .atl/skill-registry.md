## Compact Rules

### go-testing (Go + Bubbletea)
- Table-driven tests with subtests: `t.Run(tc.name, ...)`
- Use `testing.T.Helper()` in helpers
- For Bubbletea TUIs: use `github.com/charmbracelet/x/exp/teatest`
- Prefer `testify/require` for fatal assertions, `assert` for soft
- File naming: `_test.go` next to source; package `foo_test` for black-box
- Use `t.TempDir()` for filesystem tests; never hand-roll temp dirs
- Golden files under `testdata/` with `-update` flag pattern

### commit-and-push
- Conventional Commits: `type(scope): subject`
- Types: feat, fix, docs, style, refactor, test, chore
- No AI attribution / Co-Authored-By lines
